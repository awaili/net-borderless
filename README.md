# Aegis（工作代号）

> 跨平台、可观测、自适应的开源代理客户端 —— 下一代 Shadowrocket。

它不只是一个"开关"。它是一个能告诉你**网络正在发生什么**、并且能**自己修好大部分问题**的个人网络系统。

## 产品原则（TL;DR）

1. **数据不出本地** —— 所有统计、学习、诊断在设备上完成，遥测默认关闭。
2. **默认安全** —— Kill switch 默认开启；断连时丢包，绝不裸奔。
3. **诊断是一等公民** —— 任何"不通"都能被解释清楚，并给出下一步动作。
4. **开源核心，可复现构建** —— 对代理工具，闭源本身就是信任缺陷。
5. **兼容生态** —— sing-box / Clash 配置可导入，迁移成本为零。
