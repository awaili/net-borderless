# 04 · 路线图与里程碑

版本 v0.1（草案） · 2026-09-30 · 对应 PRD v0.1

---

## 0. 总体策略

**先桌面、后移动。** 理由：

1. 桌面无 App Store 审核，规则引擎、诊断、可观测性可以快速迭代验证；
2. iOS Network Extension 是最大的工程风险（内存上限、审核），必须在核心稳定后再投入；
3. 桌面开源免费是获客与口碑入口，给 iOS 付费版蓄水。

人力假设：2 名全职工程师（1 核心/协议、1 平台/UI）+ 1 名兼职设计。以下工期按此估算；4 名全职可压缩约 40%。

## 1. 里程碑

### M0 · 核心引擎验证（第 1–3 月）

**目标**：证明"Rust 核心 + 自适应策略"这条技术路线成立。

- 交付：`aegis-core` CLI（无 GUI，TUN + mixed 入站）
  - P0 协议全量：ss2022 / trojan / vless+reality / http / socks / wireguard
  - 规则引擎 v1（trie + LPM + 逻辑表达式）+ sing-box 规则集加载
  - url-test / fallback 策略组 + 探活摘除回融
  - DNS：直连 + DoH 上游 + split-DNS
  - 本地 API v1 + CLI 状态查看
- **验收门**：
  - [ ] 与 sing-box 互通测试 5 个协议全绿（双向）
  - [ ] iperf3 单核 ≥ 1Gbps；1 万连接稳定 24h 内存 < 200MB（桌面）
  - [ ] 故障注入：节点宕机 → 30s 内自动切换
  - [ ] 规则匹配 p99 < 50µs，fuzz 通过

### M1 · 桌面公测（第 4–6 月）

**目标**：第一个有真实用户的版本，验证可观测性与诊断两个差异化。

- 交付：macOS + Windows GUI（Tauri 壳 + 本地 API）
  - 状态仪表盘、连接面板、流量图表
  - 一键诊断 v1（8 项 checklist）
  - 规则建议卡片 v1
  - sing-box / Clash 配置导入；订阅 URL 导入
  - 服务模式（UI 退出网络不断）
- **验收门**：
  - [ ] 公测 500 用户，周留存 > 60%
  - [ ] 诊断故障注入用例正确率 > 90%
  - [ ] 崩溃率 < 0.5% 会话
  - [ ] dnsleak / ipv6 leak 自动化用例零泄露

### M2 · iOS 内测（第 7–10 月）

**目标**：攻克 NE，达到 App Store 可发布品质。

- 交付：iOS App + Packet Tunnel Provider
  - 核心复用（`aegis-tun-apple` glue）
  - 向导式首次配置；状态/连接/规则三 Tab（移动端信息架构）
  - Kill switch + 凭据 Keychain 化
- **验收门**：
  - [ ] NE 常驻 < 40MB、24h 后台不重启（真机矩阵：新旧机型各 2 台）
  - [ ] 开启到可用 < 2s；连续使用 1h 额外耗电 < 5%
  - [ ] TestFlight 300 人，崩溃率 < 1%

### M3 · 1.0 正式发布（第 11–12 月）

- 交付：
  - iOS 全球上架（不含中国大陆区）+ macOS Developer ID 直分发 + Windows + Scoop/Winget
  - 签名订阅清单；Hysteria2 / TUIC；流媒体解锁检测
  - 桌面 Git 同步；smart 策略组
- **验收门**：1.0 后 30 天内：App Store 评分 ≥ 4.5；诊断建议采纳率 ≥ 40%；零 P0 安全事件。

### 2.0 方向（第 13 月起）

- 个人 Mesh（WireGuard，家庭共享）→ 云端 E2E 加密同步（Pro）
- Android 端
- 链式代理 / 多跳

## 2. 风险清单

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| iOS NE 内存超标被系统杀 | 中 | 致命 | M0 就建立内存预算分解与压测门；连接上限/缓存 LRU 兜底 |
| App Store VPN 审核被拒（5.4） | 中 | 高 | 材料完备（隐私政策/日志政策）；同类先例（Surge/Stash）申诉路径；TestFlight 先行验证 |
| 协议矩阵维护跟不上生态 | 高 | 中 | 协议 crate 化隔离 + 社区贡献（开源）；只承诺 P0 稳定接口 |
| sing-box/Clash 导入兼容长尾 | 高 | 低 | 导入失败给 diff 级报告 + 手动映射；不阻塞主流程 |
| 桌面开源版被闭源商用 | 低 | 中 | 核心 GPL-3.0 |
| 两人团队 GUI 工期失控 | 中 | 中 | Tauri 薄壳 + API 驱动；移动端信息架构刻意做减法 |
| 法律与合规（发行地区） | 低 | 高 | 工具中立、不内置资源、不进中国区；发行主体与用户协议按同类产品对齐 |

## 3. 需要立即决策的开放问题

1. **产品正式名**（"Aegis" 仅工作代号，商标可用性待查）。
2. **macOS 首发是否同时做 MAS 版**（沙盒会限制部分 NE 能力，建议首发不做）。
3. **smart 组打分参数**的初始值与调参策略（M0 末 A/B 离线回放定参）。
4. **诊断报告的脱敏上报**默认值设计（原则已定 opt-in，粒度待定）。
